# Minik İngilizce

3 yaşındaki çocuklar için dokun-dinle İngilizce kelime oyunu. Kelimeleri Türkçe ve İngilizce seslendirir.

- 👂 **Dinle:** Karta dokun, kelimenin Türkçesini ve İngilizcesini duy ("Kedi... Cat!").
- 🔍 **Bul:** "Where is the cat?" sorusunu dinle, doğru karta dokun.

13 oda var: hayvanlar, renkler, meyveler, sebzeler, yiyecekler, sayılar, şekiller, taşıtlar, oyuncaklar, giysiler, vücudumuz, duygular ve gökyüzü.

Sadece HTML, CSS ve JavaScript kullanıyor, sunucu gerekmiyor. Hayvan sesleri [Pixabay](https://pixabay.com/sound-effects/)'den alındı.

**iPad / iPhone'a eklemek için:** Safari'de sayfayı aç, sonra **Paylaş > Ana Ekrana Ekle** de.
